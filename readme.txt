Site institucional da Naturalle.

O conteúdo veio do site naturalle.com.br: apresentação, quem somos, nutrição humana, nutrição animal, fichas técnicas dos produtos e política de privacidade.

Para visualizar:

python3 -m http.server 4173

Abra http://localhost:4173

Para regenerar as páginas depois de editar data/site.json:

python3 scripts/build.py
